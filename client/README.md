# Cost of Living Dashboard

## Requirements

- Node.js (v18 or higher recommended)
- npm (v9 or higher recommended)

## Tech Stack

- **React** v19.2.0
- **Vite** v7.2.4
- **D3.js** v7.9.0
- **TopoJSON** (via D3)

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. (Optional) Re-process data:

   ```bash
   npm run process-data
   ```

   _Note: Requires Node.js environment._

3. Run locally:
   ```bash
   npm run dev
   ```
